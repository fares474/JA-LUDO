# FARES LUDO

A Flutter starter project for an online Ludo game concept.

## Current status

This repository currently contains the first UI prototype:
- Home screen
- Public/private room list mockup
- Gift catalogue mockup
- Player profile mockup
- Basic Ludo board illustration

**Important:** This is not yet a playable online game. It does not currently include Ludo rules, matchmaking, a backend, accounts, live voice chat, real payments, or production security.

## Run locally

Install Flutter, then run:

```bash
flutter pub get
flutter run
```
